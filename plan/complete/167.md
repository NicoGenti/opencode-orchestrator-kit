## Goal

Stop the silent disablement of a connected, granted Code Review Graph under OpenCode V2 Code Mode: replace the six agent prompts' rule that equates absence from the native tool catalog with "CRG is not configured" by a two-signal detection rule (the delegation's `Code Graph: present` note, or the runtime exposing `code-review-graph_*` tools through the native list or the Code Mode catalog inside `execute`), land it with the pinned test assertions and the regenerated asset mirrors in lockstep, and document CRG setup canonically so the profiler's dangling reference resolves.
