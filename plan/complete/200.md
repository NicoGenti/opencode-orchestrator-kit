**Goal**: fornire agli utenti una pagina Code Mode ≤1 pagina e una risposta verificata sulla configurazione `mcp.servers`/`codemode`.

**File toccati**:

- `docs/CODE-MODE.md` (nuovo; raccomandato come canonical home per non gonfiare README).

**Dipendenze**: subdelega `librarian` (o `websearch`) per recuperare/verificare la fonte upstream OpenCode su `mcp.servers` e `codemode`; nessuna dipendenza runtime.

**Acceptance Criteria**:

- Docs Code Mode ≤1 pagina.
- Risposta su `mcp.servers` + `codemode` supportata da fonte upstream verificata, oppure esplicitamente marcata **non verificabile**.
- Shape raccomandata della dichiarazione `mcp.servers` fornita (chiave `code-review-graph` in `.opencode/opencode.jsonc`).
- Marker release-cut `README.md:93` e `:115` NON toccati.

**Verifica**:

- `bun test tests/phase3-documentation.test.ts` (README/QUICKSTART constraints).
- `bun run format:check` sul contenuto blob LF (NON `--stdin-filepath` senza `--check`).

### Phase P2 — smoke check

**Goal**: dimostrare end-to-end che un tool CRG è chiamabile via `execute` in una sessione V2 Code Mode reale.

**Dipendenze**: P1 (shape raccomandata `mcp.servers`); accesso a una sessione V2 Code Mode con CRG MCP server configurato.

**Acceptance Criteria**:

- Una chiamata `execute` a `tools["code-review-graph"].<tool>({...})` restituisce un risultato non-errore.

**Verifica**:
