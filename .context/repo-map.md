# Repo Map

> Navigation aid generated by the profiler on 2026-11-12. Not evidence: verify against source files.

## Stack

- Bun 1.2.21 + TypeScript 5.6.3; Python and POSIX shell for a few scripts.
- Published artifact: OpenCode 2 plugin in `plugin/` (ESM, peer `@opencode/plugin ^2.1.0`).
- Site: Vite 8 + React 18 + Tailwind 4 (`src/`, `docs-src/`) → GitHub Pages.
- Tests: `bun test`; quality gates: typecheck, lint (ESLint), format (Prettier), `sync-assets --check`.
- Kit sources are Markdown (`agents/`, `extras/`, `command/`, `skills/`) mirrored byte-for-byte into `plugin/assets/`.

## Key Entry Points

- `AGENTS.md` — the contract every session loads; routing table lives in `agents/orchestrator.md`.
- `plugin/src/index.ts` — plugin entry: registers agents, tiers, commands, skills, permissions, `plan_board` tool.
- `scripts/plan-board.py` — canonical plan-board mutation CLI (exit 0/1, JSON).
- `plugin/src/plan-board.ts` — TypeScript port of the same CLI; `plugin/src/plan-board-tool.ts` wraps it as the native tool.
- `scripts/sync-assets.ts` — regenerates `plugin/assets/`; run after editing agents/extras/skills/commands.
- `command/start-session.md` — session bootstrap slash command (plus `recall`, `research-mode`, `close-session`, `quick`).
- `package.json` scripts — `test`, `typecheck`, `lint`, `format:check`, `sync-assets`, `build`, `bun:audit`.
- `.github/workflows/test.yml` — the gate every PR runs.
- `install.sh` — legacy V1 install path (still covered by installer tests).
- `templates/design-rules.md` — canonical design-rules skeleton seeded into `.context/DESIGN-RULES.md`.
